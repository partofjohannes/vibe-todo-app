# Emils Schiffsrennen

Ein Rennspiel mit echten Kreuzfahrtschiffen, gemacht für Emil (6).

**Starten:** `index.html` doppelklicken. Es läuft in jedem Browser, auch auf Tablet und Handy, ohne Installation.

## So geht's
1. Quartett-Karte mit dem Lieblingsschiff antippen (AIDAnova, Queen Mary 2, Icon of the Seas, Mein Schiff 1, MSC World Europa, Disney Wish).
2. Strecke wählen: Karibik, Nordsee oder Fjord. Jede Strecke hat neue Kurven, sie wird bei jedem Rennen neu gebaut.
3. Gegner wählen: **Gemütlich** (mit Lenkhilfe, die das Schiff sanft durch die Kurven führt) oder **Flott**.
4. „Leinen los!“ und dann lenken.

## Steuerung
- Lenken: Pfeiltasten (oder A/D), auf dem Tablet die großen Pfeilknöpfe
- Hupen: Leertaste oder „Tuuut!“-Knopf. Segelboote und Kutter fahren dann schnell zur Seite.
- Goldene Sterne einsammeln gibt kurz Turbo.
- Wer gegen Bojen, Felsen, Eisschollen oder Sandbänke fährt, wird langsamer. Kaputt geht nichts.

Die Schiffswerte auf den Karten sind ungefähre Angaben.
